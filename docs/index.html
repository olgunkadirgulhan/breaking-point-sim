Breaking Point Sim

Breaking Point Sim publishes short 3D physics simulations: crush tests, impacts, shattering and fluids, built and rendered in Blender. Every video is a computer simulation; nothing real is destroyed and nothing is presented as real footage.

This site describes the publishing tool behind the Breaking Point Sim YouTube channel. The tool renders our own original simulations and uploads them to our own channel using the YouTube Data API. It does not access any other user's data.
