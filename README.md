# Breaking Point Sim

3D physics simulation Shorts (crush tests, impacts, shattering, fluids), built in Blender and rendered on GitHub Actions (CPU, one job per round).
Every video is labeled as a simulation in its title and description.

- `brand.py` — banner, profile picture, channel description (`--apply` pushes them to YouTube)
- `docs/` — homepage, privacy policy and terms (GitHub Pages, used on the OAuth consent screen)
